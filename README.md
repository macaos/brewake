# Brewake

A macOS menu bar app that keeps your Mac awake. Click the cup, pick how long, and your Mac and its display stay awake.

**[Download the latest version](https://github.com/macaos/brewake/releases/latest/download/Brewake.dmg)**
· macOS 13 or later · Apple Silicon and Intel

- Try it free for 7 days. No account and no card.
- After that, $2.99 once. One license covers up to 3 Macs.
  [Buy a license](https://brewake.ashsoft.us/r/github)
- When a new version is out, the menu shows **Update to…**. To check right away, choose **Check for Updates…** from the menu.

This repository only holds the releases. The source code is not public.
